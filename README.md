# 赛博皮影戏

基于手势识别的交互式皮影戏网页作品。打开摄像头，用手势操控皮影角色，配合光影特效重现传统皮影戏。

## 在线体验

https://hhyyxx0220.github.io/shadow-play/

## 使用方法

1. 用 Chrome / Edge / Safari 打开上面的网址
2. 允许浏览器调用摄像头
3. 按照页面提示用手势操控皮影

## 手势玩法

| 手势 | 招式 | 效果 |
|---|---|---|
| ✊ 握拳 | 斩 | 影人腾空飞踢，挥出朱砂刀光 |
| 🖐 张掌 | 术 | 施术：扩散法环 + 上浮符文 |
| 🤏 捏合 | 弹 | 蓄力聚能球，松手发射光弹 |
| ✌️ 双指 | 书 | 题字盖印（左「影」右「灯」） |
| 🤟 摇滚手 | 雷 | 天雷直劈掌心 |
| 3️⃣ 三指 | 扇 | 三道扇形风刃 |
| 👍 竖拇指 | 揖 | 金光福泽 +「福」字 |
| 👌 OK 手 | 印 | 结印法阵 |
| ✊✊ 双拳 | 合斩 | 双掌间交叉巨刃 |
| 🙌 双掌同张 | 合璧 | 落雷 + 闪屏 +「灭」 |

## 本地运行

项目需要 HTTP 服务器环境（摄像头功能限制），不能直接双击 index.html 打开。双击 `start.bat` 一键启动。

## 技术说明

- 手势识别：MediaPipe Hand Landmarker（本地离线运行，无外部依赖）
- 音效：Web Audio API 实时生成（锣鼓点合成音）
- 背景音乐：assets/audio/bgm.mp3（本地循环播放，右上角可开关）
